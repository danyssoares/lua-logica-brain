# Skills

Cópia de apoio das skills usadas com o Claude. A fonte de verdade continua sendo o ambiente de skills do Claude — isto aqui serve como backup versionado e documentação pública do método.

- `aion/` — interpretação astrológica + psicologia profunda
- `eclipse-express/` — leitura express de eclipse (roteiro de áudio + PDF)
- `estelar-sinastria/` — leitura de compatibilidade (sinastria)

Todos os exemplos em `input-examples/` usam dados fictícios ("Nome da Consulente") — nunca substituir por dados reais de clientes.
